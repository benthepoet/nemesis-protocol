# Reference Board — Security Crew (baseline infantry, design doc §4.5)

**Board v1 | gathered 2026-07-30 | feature p1-enemy-baseline | owner: Kimi K3**

Scope: the ship's security crew — baseline infantry, sidearm-armed, industrial naval workwear + light tactical gear. Covers silhouette, materials, lighting per charter §1 (reference-first). This board **starts** here per the §4.5 roster note ("Kimi's reference boards and asset passes for P1 target: security crew, heavy/exosuit, android"); it is consumed by the hero security-crew model in `p1-visual-pass` (P1 #9, milestone M-P1) — this feature ships blockout capsules only.

**Design synthesis (binding for the hero pass):** security crew = **industrial coverall base layer** (refs 5–6) + **light tactical over-layer** — chest rig/harness, sidearm holster, cap or comms headset (refs 1, 3–4). No heavy armor (that silhouette belongs to the heavy/exosuit tier). Palette: hull-steel neutrals with a `#ff5252`-family hostile accent kept small (shoulder light/insignia) — red owns hostile (visual §3) but the *silhouette* must read hostile first (visual §7 rule 2). Sidearm only at AL0–AL1 (design doc §4.5) — rifle carry is an AL2+ visual and does not exist at P1.
